# 자극 파일 위치

자극 확정 후 다음 파일을 이 폴더에 두거나, `src/data/stimuli.js` 의 URL을 외부 호스팅 URL로 변경하세요.

```
ua_360.mp4         (우크라이나 360° 영상, equirectangular)
ga_360.mp4         (가자 360° 영상, equirectangular)
ua_still1..6.jpg   (우크라이나 텍스트 자극용 still 6장)
ga_still1..6.jpg   (가자 텍스트 자극용 still 6장)
```

대용량 (>100MB) 파일은 GitHub LFS 또는 외부 CDN(Cloudflare R2, Bunny CDN) 사용 권장.
